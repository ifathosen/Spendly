Firebase সেটআপ গাইড

সময় লাগবে ~৮ মিনিট। একবারই করতে হবে।

  1. যান: console.firebase.google.com → Create a project → নাম দিন Spendly → Google Analytics চাইলে বন্ধ রাখতে পারেন → Create project।
  2. বাম মেনু: Build → Firestore Database → Create database → Start in production mode → Create।
  3. Firestore-এর Rules ট্যাবে গিয়ে আগের লেখা মুছে নিচের কোড বসিয়ে Publish করুন:
    rules_version = '2';
service cloud.firestore {
  match /spendly/{uid} {
    allow read, write: if request.auth != null
      && request.auth.uid == uid;
  }
}
  4. বাম মেনু: Build → Authentication → Get started → Sign-in method ট্যাব → Google → Enable → নিজের Gmail (support email) বেছে Save।
  5. Authentication-এর Settings ট্যাব → Authorized domains → Add domain → লিখুন: ifathosen.github.io → Add।
  6. বাম উপরের ⚙️ → Project settings → নিচে Your apps → Web আইকন </> → App nickname: Spendly → Register app।
  7. স্ক্রিনে const firebaseConfig = { ... } লেখা কোড দেখাবে — পুরো অংশটা কপি করুন।
  8. এই অ্যাপে ফিরে এসে বক্সে পেস্ট করে Save & Continue → তারপর Sign in with Google। ব্যস, শেষ! 🎉
✅ এরপর থেকে অ্যাপ খুললেই সরাসরি ড্যাশবোর্ড আসবে। প্রতিটি এন্ট্রির পর উপরে শুধু লেখা উঠবে: ☁️ Cloud saved · সময় — সেটাই আসল অবস্থা, কোনো বাটন চাপতে হবে না।
