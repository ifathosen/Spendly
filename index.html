Client ID পাওয়ার ধাপ

কম্পিউটার বা ফোনের ব্রাউজারে করুন। সময় লাগবে ~৭ মিনিট।

  1. যান: console.cloud.google.com → নিজের Gmail দিয়ে লগইন করুন।
  2. উপরে বামে প্রজেক্টের নামের পাশে ক্লিক → New Project → নাম দিন Spendly → Create। তারপর ঐ প্রজেক্টটি সিলেক্ট করুন।
  3. বাম মেনু (☰) → APIs & Services → Library → সার্চ করুন Google Drive API → Enable চাপুন।
  4. APIs & Services → OAuth consent screen → External বেছে Create → App name: Spendly, নিজের ইমেইল দুই জায়গায় দিন → Save করে এগিয়ে যান। শেষে Test users-এ নিজের Gmailটি যোগ করুন।
  5. APIs & Services → Credentials → + Create Credentials → OAuth client ID → Application type: Web application।
  6. Authorized JavaScript origins-এ Add URI দিয়ে এটি বসান:
    https://আপনার-github-username.github.io
    (আপনার আসল GitHub Pages ডোমেইন — শুধু ডোমেইন, পেছনে কোনো পাথ নয়।)
  7. Create চাপুন → একটি Client ID দেখাবে → কপি করুন।
  8. এই অ্যাপে ফিরে এসে Client ID-টি বসিয়ে Save & Continue চাপুন। ব্যস!
✅ এরপর থেকে "Sign in with Google" চাপলেই লগইন হবে, আর প্রতিটি এন্ট্রি নিজে নিজেই আপনার Drive-এ সেভ হবে।
